## Usermods

If you modified the Burninator and want to share it with others, feel free to contribute a user mod.

- Fork the repository.  
- Create a folder in `Burninator/Usermods` with a descriptive name.  
- Add your files and optionally include a README with instructions or further information.  
- Create a pull request.
