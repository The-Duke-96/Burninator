# Mellow Fly Fluxheat with ASPL level sensor adaptation
UHF cowl and MGN12/9/7H Backplate adjusted for the Mellow Fly Fluxheat with ASPL level sensor, using the CAD parameters as well as a shim to mount the aspl pcb between the EBB36 mount and EBB36 pcb.
As by userrequest, I have added it here as a usermod.

## fly-aspl_adapter.stl
<img src="https://github.com/The-Duke-96/Burninator/blob/main/Usermods/mellow-fly-fluxheat%2Baspl_adaptation/fly-aspl_adapter.png" width="1050" height="580">

**note:**
- Put a M3 heat insert into the center hole.
- A litte bit of support is needed.
- don't  forget the appropriate belt clampage parts 
- Using the fly-aspl_adapter, will extend the toolhead into the back by 8mm! Connectors on the side should be still accessable.
